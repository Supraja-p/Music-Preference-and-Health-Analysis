# EDA & Music Genre Impact on Mental Health
This project explores the relationship between music genre preferences and self-reported mental health conditions like anxiety and depression using survey data. It was conducted as part of an academic project at Indiana University Indianapolis and focuses on statistical analysis and predictive modeling techniques in Python.

📊 The entire exploratory data analysis (EDA) and modeling were performed using Python libraries and Jupyter Notebooks.

## 🎯 Project Goal
To investigate whether music listening habits—such as favorite genres, streaming duration, and platform usage—are statistically associated with mental health indicators (e.g., anxiety, depression, insomnia).

## 🛠️ Tools & Technologies
- Python Libraries: Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn, SciPy

- Platform: Jupyter Notebook

- Dataset: Kaggle - Music & Mental Health Survey Dataset

- Statistical Tests: Correlation Matrix, T-Test

- ML Models: Linear Regression, Decision Tree Regressor, Support Vector Regressor

## 📌 Key Steps
- Data Cleaning
  - Removed null entries and standardized categories.
- Exploratory Data Analysis (EDA)
  - Age distribution, streaming habits, genre popularity
  - Visualization of mental health scores
- Statistical Analysis
  - Correlation matrix for mental health indicators and music habits
  - T-tests to analyze differences in anxiety/depression based on listening duration
- Machine Learning
  - Built regression models to predict mental health scores from music habits

## 📊 Highlights
- Spotify was the most-used streaming platform
- Rock and Pop were the top genres
- Weak but visible correlations between streaming hours and depression
- T-test showed significant difference in depression scores (p < 0.01) between high vs. low streamers

## 🔚 Conclusion
While no strong causal relationships were found, patterns suggest streaming behavior may reflect underlying mental health trends. This study opens the door to using music listening data as a potential signal in mental health assessments.
